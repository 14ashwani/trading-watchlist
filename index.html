Connect Firebase

One-time setup for real-time sync across all your devices

1
Go to Firebase Console
Open console.firebase.google.com — sign in with your Google account
2
Create a New Project
Click "Add project" → Name it "trading-watchlist" → Disable Google Analytics (not needed) → Click "Create project"
3
Add a Web App & Copy Config
Click the </> Web icon → Name it "TW Pro" → Click "Register app" → You'll see a firebaseConfig object — copy the entire object
4
Enable Firestore Database
Left menu → Build → Firestore Database → "Create database" → Choose "Start in test mode" → Select region → "Enable"
5
Enable Google Sign-In
Left menu → Build → Authentication → "Get started" → Click "Google" → Toggle Enable → Add your email as support email → "Save"
6
Add Authorized Domain
Still in Authentication → "Settings" tab → "Authorized domains" → "Add domain" → Type your GitHub Pages URL: 14ashwani.github.io
